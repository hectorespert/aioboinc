1""" 

2The types of the replies, as TypedDict 

3 

4A reply is still a dict, keyed by the names of the elements BOINC sends. These types say which keys 

5it has and the type of each, for an editor and a type checker, and change nothing at run time. 

6 

7A key is NotRequired when BOINC writes it only sometimes, or did only in some versions; BOINC has 

8written the others since 7.8, of 2017, at the latest. 

9A reply may also have keys these do not list, from a newer BOINC client. A state or a reason is its 

10enum, or an int for a value the enum does not have yet. 

11""" 

12
